# Frontend

Aplicación React creada con Vite a partir del [Dashboard oficial de Material UI v9.4.0](https://github.com/mui/material-ui/tree/v9.4.0/docs/data/material/getting-started/templates/dashboard). Se usa la variante JavaScript y el tema claro es el modo inicial.

```bash
npm install
npm run dev
```

El selector incluido en el dashboard permite cambiar posteriormente entre los modos claro, oscuro y automático.
