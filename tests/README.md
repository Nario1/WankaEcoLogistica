# Pruebas del proyecto

Las pruebas automatizadas del Sprint 1 viven en `backend/tests`, agrupadas por módulo entregado:

- `auth.test.js`: autenticación y control de roles (EN-002).
- `orders.test.js`: pedidos y validación geográfica (US-001 / EN-006).
- `vehicles.test.js`: flota (US-002).
- `drivers.test.js`: conductores y límite de jornada (US-003).

Ejecutar desde `backend`: `npm test`.
