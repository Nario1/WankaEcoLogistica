# WankaEcoLogística Huancayo

Proyecto académico del equipo Wanka, orientado al diseño y desarrollo de una plataforma web para optimizar rutas sostenibles de última milla en **Huancayo - Junín - Perú**.

La propuesta busca reducir distancia recorrida, tiempos de entrega, consumo de combustible y emisiones, manteniendo una experiencia de trabajo clara para el equipo y útil para los actores logísticos involucrados.

**Toque del equipo:** una solución pensada con identidad local, enfoque práctico y mejora continua, hecha para crecer con el contexto de Huancayo.
