## 1. Nivel 1: Diagrama de Contexto

Este nivel muestra el panorama general del sistema **WankaEcoLogística**, los usuarios (actores logísticos) que interactúan con él y los sistemas externos de los que depende para su funcionamiento integral (como servicios de mapas geográficos y mensajería).

```mermaid
graph TD
    User[Operador Logístico / Conductor] -->|Utiliza via HTTPS| System[Sistema WankaEcoLogística]
```

## 3. Nivel 3: Diagrama de Componentes

Este diagrama detalla la estructuración interna de los módulos que componen el contenedor principal de la API Backend (FastAPI). Se evidencia una arquitectura por capas limpias, separando las interfaces de red, la lógica algorítmica y el acceso a datos.

```mermaid
graph TD
    subgraph backend["Contenedor API Backend - Python / FastAPI"]
        Router["Controladores / Endpoints"]
        Sec["Middleware de Seguridad y Auth"]
        SvcRuteo["Servicio de Optimización y Ruteo"]
        SvcNegocio["Servicios Transaccionales Core"]
        Repo["Capa de Repositorios / ORM"]

        Router -->|"Intercepta petición para validar"| Sec
        Sec -->|"Retorna Token Válido"| Router
        Router -->|"Delega el cálculo matemático"| SvcRuteo
        Router -->|"Delega lógica de negocio - CRUD"| SvcNegocio
        SvcRuteo -->|"Requiere coordenadas y grafos"| Repo
        SvcNegocio -->|"Persiste entidades"| Repo
    end

    WA["SPA - React"] -->|"Peticiones HTTP"| Router
    Repo -->|"Ejecuta Queries"| DB[(PostgreSQL)]
```
