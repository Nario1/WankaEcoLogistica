## 1. Atributos de Calidad y Escenarios (ISO/IEC 25010)

El siguiente catálogo define los requisitos no funcionales del sistema mediante **Escenarios de Calidad** estructurados y con métricas SMART, eliminando cualquier ambigüedad cualitativa en los criterios de aceptación técnica.

### 1.1. RNF-001: Rendimiento (Eficiencia de desempeño)
- **Fuente:** Operador logístico concurrente.
- **Estímulo:** Petición de generación y cálculo de ruta optimizada con 50 puntos de entrega.
- **Entorno:** Operación normal con carga máxima (80% capacidad).
- **Artefacto:** Motor de Optimización de Rutas / Backend.
- **Respuesta:** Procesar la solicitud algorítmica y retornar el trazado geoespacial.
- **Medida SLA:** Latencia ≤ 3.5 segundos en el percentil 95 (P95).

---

### 1.2. RNF-002: Seguridad
- **Fuente:** Atacante externo.
- **Estímulo:** Intento de inyección SQL o XSS en los endpoints de autenticación y registro.
- **Entorno:** Producción.
- **Artefacto:** API Gateway / WAF.
- **Respuesta:** Bloquear la petición maliciosa, registrar evento de auditoría y notificar al administrador o SOC.
- **Medida SLA:** 0% de vulnerabilidades críticas y altas ejecutables según el estándar OWASP Top 10.

---

### 1.3. RNF-003: Fiabilidad (Disponibilidad)
- **Fuente:** Infraestructura cloud.
- **Estímulo:** Caída de un nodo en la zona de disponibilidad primaria.
- **Entorno:** Operación 24/7.
- **Artefacto:** Cluster K8s / Base de Datos.
- **Respuesta:** Failover automático hacia la zona secundaria manteniendo la integridad.
- **Medida SLA:** RTO (Tiempo de Recuperación) ≤ 30 segundos, RPO (Punto de Recuperación) ≤ 5 segundos, SLA global mensual ≥ 99.9%.

---

### 1.4. RNF-004: Usabilidad (Operabilidad)
- **Fuente:** Nuevo conductor o planificador logístico.
- **Estímulo:** Primer ingreso a la plataforma para gestionar o visualizar una ruta.
- **Entorno:** Operación diaria bajo presión de tiempo.
- **Artefacto:** Interfaz Web de Usuario (UI) responsiva.
- **Respuesta:** Completar la tarea crítica (ej. actualizar estado de pedido) sin requerir asistencia técnica externa.
- **Medida SLA:** Tiempo de aprendizaje (Onboarding) ≤ 15 minutos; Tasa de error de usuario no recuperable ≤ 5%.

---

### 1.5. RNF-005: Mantenibilidad (Modificabilidad)
- **Fuente:** Equipo de desarrollo interno.
- **Estímulo:** Cambio de proveedor de la API de Mapas y Tráfico (ej. migrar de Google Maps a Mapbox).
- **Entorno:** Entorno de Desarrollo y Staging.
- **Artefacto:** Capa de servicios de integración / Microservicios.
- **Respuesta:** Implementar y desplegar el nuevo proveedor sin alterar la lógica de negocio central del motor de ruteo.
- **Medida SLA:** Esfuerzo de modificación ≤ 16 horas hombre; Cobertura de pruebas unitarias en código nuevo ≥ 85%.

---

### 1.6. RNF-006: Compatibilidad (Coexistencia)
- **Fuente:** Conductor en ruta.
- **Estímulo:** Consulta constante del mapa para la siguiente entrega.
- **Entorno:** Conectividad móvil 3G/4G inestable por variaciones topográficas en Huancayo.
- **Artefacto:** PWA (Progressive Web App) / Frontend móvil.
- **Respuesta:** Renderizar la información cacheada y actualizar el progreso asíncronamente cuando vuelva la red.
- **Medida SLA:** Soporte en navegadores basados en Chromium ≥ 90 y Safari ≥ 14, tiempo de carga inicial de vista ≤ 3.0 segundos bajo perfil 3G lento.

---

### 1.7. RNF-007: Adecuación Funcional (Precisión)
- **Fuente:** Motor algorítmico de ruteo.
- **Estímulo:** Cálculo de ahorro de métricas post-ejecución.
- **Entorno:** Operación regular de simulación o pruebas UAT.
- **Artefacto:** Módulo de Reportes de Sostenibilidad.
- **Respuesta:** Generar el trazado exacto y comparar contra el modelo de entrega manual secuencial.
- **Medida SLA:** Margen de error en aproximación de coordenadas ≤ 10 metros; Reducción verificable de distancia total recorrida ≥ 15% respecto a la línea base.
