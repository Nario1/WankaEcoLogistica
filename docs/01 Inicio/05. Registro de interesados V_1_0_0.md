## Matriz Poder / Interés

- **Alto Poder / Alto Interés (Gestionar de cerca):**
  - Docente Guía (STK-01): Toma decisiones sobre la evaluación y aprobación del proyecto.
  - Project Manager (STK-02): Dirige el rumbo del proyecto y gestiona recursos.
  - Cliente / Sponsor Real (STK-05): Principal beneficiario, define las necesidades de negocio y valida el producto.
- **Alto Poder / Bajo Interés (Mantener satisfecho):**
  - Directivos de la Facultad de Ingeniería: Regulan estándares académicos.
- **Bajo Poder / Alto Interés (Mantener informado):**
  - Lead Developer y Desarrolladores (STK-03, STK-04): Se encargan del aspecto técnico del proyecto y necesitan comunicación constante sobre las decisiones del PM.
- **Bajo Poder / Bajo Interés (Monitorear):**
  - Usuarios Operativos (Conductores de la empresa logística): Monitorear la adaptabilidad al sistema una vez entregado el MVP.
